## ⚡ Features

- **200+ Working User Agents** - Random rotation, undetectable
- **Multi-Platform** - Windows, Mac, Linux, Android, iOS
- **Multi-Browser** - Chrome, Firefox, Safari, Edge, Opera
- **Data Extraction** - Emails, Phones, Social Links, Metadata
- **Export Formats** - JSON, CSV, SQLite
- **Stealth Mode** - Auto-rotation, random delays, full headers
- **Multi-Threaded** - Fast parallel scraping
- **Separated Database** - Easy to update user agents
